## Adding a problem

Create a folder in the topic, e.g. `problems/sliding_window/0003_longest_substring/`, with your
accepted solution (`solution.py` and/or `solution.js`) and a `README.md` write-up. You can copy
the headings from `_template/README.md`; the `# 3. Title` heading and the `**Difficulty:**` line
are what the progress table reads.

Topics: `arrays_hashing`, `two_pointers`, `sliding_window`, `stack`, `binary_search`,
`linked_list`, `trees`, `graphs`, `dynamic_programming`, `greedy`.
